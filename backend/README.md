# SkillOrbit AI – Backend

Express.js + TypeScript + MongoDB REST API server.

## Development

```bash
npm install
npm run dev       # starts on http://localhost:5000
```

## Build

```bash
npm run build
npm start
```

## Health Check

```
GET http://localhost:5000/api/health
```

## Environment Variables

Copy `.env.example` → `.env` and configure each value.
